Output: Telegram

The bot that sends you the ads, with Keep / Reject buttons. Each profile has its own bot (two profiles may share one).

Bot of this profile

The steps below set up the bot chosen here: its token, its chat, a test.

1. Create your bot

  1. In Telegram, open @BotFather and send /newbot.
  2. Choose a name and a username ending in bot.
  3. Copy the token it gives you and paste it below. Keep it private.

2. Link your chat

  1. Open your bot in Telegram and send it any message (e.g. "hello").
  2. Click Detect, then Use this chat next to your name.

3. Test

Don't run another program with the same bot token: it would read your clicks before this tool does.

AI

The AI that reads each ad and sorts it against your profile, once a day.

Which AI?

Gemini

  1. Go to Google AI Studio and sign in with your Google account.
  2. Create an API key and paste it below. Keep it private.

A Gemini app subscription does not include an API key, but the free tier of the API is enough for one call a day. On the free tier, Google's terms allow it to use what is sent (your profile and the day's ads) to improve its products.

Sources

Where ads come from. Switch each source on or off; the next run uses the change.

NAV / Arbeidsplassen

Norway's public job feed, with the full ad text. No setup needed.

Gmail (for Finn and LinkedIn alert emails)

  1. Turn on 2-step verification on your Google account.
  2. Create an app password and paste it below (not your normal password).

The tool opens this mailbox read-only and only reads the alert emails from Finn and LinkedIn.

Finn.no

  1. On finn.no, search jobs with your area and categories, then save the search as an alert (Søkeagent) sent by email to the Gmail address above.
  2. Optional: filter those emails into a Gmail label and enter it below.

Read the full Finn ads (only with Finn's written permission)

By default only the alert emails are read: title, employer and place. Turn this on only if Finn has given you written permission (ask their customer service: personal job search, once a day, only the ads from your own alerts).

When on, each new ad page from your alert emails is downloaded once, during the morning run, at least 5 seconds apart, with your contact email in the request header. Only the description is kept, on this computer. Never share it, and delete it when your job search ends.

LinkedIn

  1. On LinkedIn, search jobs (keywords, location), then turn on Job alert with daily emails.
  2. Make sure LinkedIn sends them to the Gmail address above (LinkedIn settings, email address).
  3. When the first alert email has arrived, click Check LinkedIn alerts.

Only the alert emails are read: title, company and place. The tool never opens linkedin.com pages (LinkedIn's terms forbid scraping), so LinkedIn ads arrive with a "limited preview" note; open the link to read them.

Phone access

Use this dashboard from your phone through Tailscale, and add it to your home screen like an app.

Status

  • Loading…

1. Always-on dashboard

The phone needs the dashboard to run all the time on this computer: a scheduled task starts it in the background when you log on to Windows (no window). It also listens to Telegram all day, so each Keep / Reject tap is saved within seconds and the application kit follows right away.

2. Tailscale address and password

This computer's name on your Tailscale network. Only your own Tailscale devices can open it.

The password is asked once on the phone, then remembered for 30 days. At least 12 characters. Changing it logs every phone out.

3. Share it on Tailscale

Runs Tailscale Serve for the dashboard's port: private to your Tailscale devices.

Public access without the Tailscale app is possible with Tailscale Funnel (port 10000). Then anyone can reach the login page and the password is the only lock: use a long one. Each login and each lock-out is reported on Telegram. To stop it: tailscale funnel --https=10000 off

4. On the phone

  1. Open the Tailscale app on the phone and check it is connected.
  2. In the phone's browser, open … and log in with the password.
  3. Add it to the home screen. Android (Chrome): menu ⋮, then Add to Home screen or Install app. iPhone (Safari): Share, then Add to Home Screen.
